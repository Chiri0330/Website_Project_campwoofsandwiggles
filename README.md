🐾 Camp Woofs and Wiggles – Dog Camp Website
📌 Project Overview

Camp Woofs and Wiggles is a fully responsive website designed for a dog care facility that offers day camp, boarding, and event services. The goal of this project was to create an engaging and easy-to-navigate platform where pet owners can quickly understand services, pricing, and how to contact the business.

This project focuses on user experience, layout structure, and visual clarity to ensure users can move through the website naturally and without confusion.

🎯 Objectives
Design a clean and modern interface for a pet service business
Present services in a clear and organized way
Create a smooth user flow from landing → services → pricing → contact
Ensure full responsiveness across all devices
Use visuals to enhance engagement while keeping the interface simple
🧠 User Experience Strategy
Clear Navigation Flow

The layout guides users through a logical sequence:

Welcome section
Services
Pricing
Contact form

This reduces confusion and helps users quickly find what they need.

Services are grouped into clear sections

Balanced layout between text and visuals
